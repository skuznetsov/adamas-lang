# Checked-union predicates

The stock-first runner compares exact native output and diagnostic-specific
rejections with the installed Crystal stdlib and an empty prelude. The String
controls explicitly reopen String so its source declaration is present; they
isolate class-object versus instance facts on the fixed String carrier.

The original no-prelude `value = String` without that declaration is a separate
known Adamas constant-publication failure, retained in the frontier evidence.
These fixtures do not certify that case or runtime mixed class/instance PHIs.
