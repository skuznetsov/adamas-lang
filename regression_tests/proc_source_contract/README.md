# Proc source contracts

Run `regression_tests/proc_source_contract_repro.sh /absolute/path/to/adamas` with `ORIGINAL_CRYSTAL_BIN` and `CRYSTAL_PATH` pointing to the reference Crystal toolchain. All compiler and program invocations use `scripts/run_safe.sh` and execute serially. Every suite qualifies all its reference cases before its candidate cases. Positives compare exact output and require clean safe-run status records; negatives require a specific source-semantic rejection and no executable. `exception_semantic` deliberately stops at semantic/HIR output, so it makes no native exception-runtime claim.

The 164 cases cover selected Proc.new source contracts, argument/destructuring binding, capture flow/storage (including the different binding rules for Proc.new and ordinary yielded blocks), result typing and ABI admission, lexical return ownership, explicit Proc annotations (including unknown source types), normalized macro block AST and chained indexing, and declared external types. They include the parser arrow, command-boundary and tuple-pattern cases exercised by these contracts. Parser AST-cache round trips and wider command-boundary regressions have separate tests. This suite does not certify full-prelude behavior, LavinMQ, or bootstrap. Dynamic class-valued captures, metaclass-versus-instance Proc signatures, exact numeric Proc#call admission, and nullable C Proc interop have separate follow-up probes.
